2. Set the scene

Click any seat in the maps above to change it. Real sensor seats are locked in hybrid mode.

Each stop frees 5–20% of occupied seats, then fills 5–20% of free ones, spread at random across all cars, applied over about 2.4 seconds so you can watch it. Physical sensor seats are never changed. Automatic stops run while a display tab is open.

Scenarios never overwrite real readings. In hybrid mode, example totals depend on the two physical seats.
